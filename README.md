# Слово

**Слово** — рідна програма для macOS, щоб показувати на проекторі під час
богослужіння Біблію, пісні, презентації, зображення, відео й оголошення.
До неї є пульт на телефоні, робоче місце оператора на планшеті й пульт у
браузері будь-якого пристрою в мережі.

Інтерфейс і порядок роботи натхненні програмою
[VisioBible](https://visiobible.org.ua). «Слово» написане з нуля: воно не
містить коду чи даних VisioBible і не пов'язане з її авторами.

## Можливості

- **Біблія** — переклади (модулі у форматі VisioBible), книги, розділи,
  вірші; кілька перекладів поруч; пошук за словами; План та Історія
  служіння; довгий вірш ділиться на сторінки.
- **Пісні** — пісенники, частини пісні (куплет, приспів…), редактор,
  кольори частин.
- **Презентації** — PDF і PowerPoint, переходи між слайдами.
- **Зображення** — показ і слайд-шоу.
- **Медіа** — відео, звук, мережеві потоки, YouTube; фонограма окремо від
  показу.
- **Екран** — монітор або вікно іншої програми на проекторі (з macOS 11).
- **Текст** — набір оголошень.
- **Виводи** — проектор (окремий екран), NDI для трансляції, веб-сторінки
  для OBS.
- **Указка й наближення** — мишею, трекпадом чи з пульта.
- **Пульт на телефоні** (Android 6 і новіші), **планшет оператора**
  (Android 5 і новіші), **пульт у браузері** — адреса `slovo.local`,
  установлення програм для Android за QR-кодом.
- **План проповіді** — проповідник складає його на планшеті заздалегідь, без
  зв'язку з програмою (своя бібліотека перекладів і пісенників: зі «Слова»,
  з каталогу модулів «Цитати з Біблії» на GitHub або з файла), а на служінні
  однією кнопкою робить головним планом «Слова». План служіння на цей час
  відкладається й потім повертається. Переклади й пісенники, яких у програмі
  немає, вона ставить собі сама.
- **Мій перегляд** на планшеті й у браузері — текстовий слайд у своєму
  оформленні (темне, світле, сепія, розмір), а не картинкою залу.
- **Мови інтерфейсу** — українська (за умовчанням), російська, англійська,
  німецька — вбудовані в програму.
- **Самоперевірка** — `--selftest` проходить сотні перевірок на живій
  програмі.

## Системні вимоги

- macOS 11 Big Sur і новіші, Intel і Apple Silicon (один універсальний
  пакет).
- NDI вбудовано в програму: бібліотека NDI безкоштовна й поширюється разом
  із програмою разом зі своїм файлом ліцензій. NDI® — зареєстрована торгова
  марка Vizrt NDI AB, [ndi.video](https://ndi.video). У сам репозиторій
  бібліотека не входить.
- Для пульта й планшета — Android 6 / Android 5 і та сама мережа Wi-Fi,
  що й комп'ютер.

## Готові збірки

У розділі [Releases](../../releases) — програма для macOS і обидві
програми для Android, щоб подивитися, як це працює.

- Програма для macOS підписана тимчасовим підписом, тож macOS при першому
  запуску скаже, що розробника не перевірено. На macOS 11–14: клацніть на
  «Слово.app» правою кнопкою → «Відкрити» → «Відкрити». На macOS 15 і
  новіших: спробуйте відкрити, потім «Системні параметри» → «Приватність і
  безпека» → «Усе одно відкрити».
- Випуски бувають **повні** (програма з усім пакетом ресурсів — перекладами,
  пісенниками, фонами, шаблонами; напр. 0.69) і **«лише програма»** (з 0.8):
  ресурси тоді завантажуються з інтернету — «Настройка» → «Ресурси з
  GitHub…», з вибором і оновленнями. Ресурси лежать окремо:
  [roman885-85/slovo-resources](https://github.com/roman885-85/slovo-resources);
  там же вибирають модулі «Цитата з Біблії» і реєстр MyBible. Свої модулі —
  «Файл» → «Імпорт модулів, шаблонів і фонів…».
- Програма сама перевіряє, чи вийшла нова версія, і оновлюється, зберігаючи
  переклади й дані.
- Інтерфейс — українською за умовчанням; російська, англійська й німецька
  вбудовані теж (меню мови). Якщо імпортувати дані VisioBible, з'являться й
  двадцять її мов.
- Android попереджає про «невідомого розробника» — це очікувано для
  програм не з Google Play: «Усе одно встановити».

## Що не входить у репозиторій

- модулі Біблії, пісенники, фони, шаблони й інші дані — їх кожен кладе свої;
- зображення (значок програми);
- ключі підпису Android і готові пакети — готові збірки лежать у Releases.

## Збирання

### macOS

Потрібні Command Line Tools (`xcode-select --install`) зі Swift 6.

```sh
git clone https://github.com/roman885-85/slovo.git
cd slovo
swift build              # швидка перевірка, що все збирається
Scripts/deploy.sh        # пакет «Слово.app» у ~/Documents/Слово
```

- Тека призначення змінюється так: `SLOVO_DEST=~/Слово Scripts/deploy.sh`.
- Підпис: якщо в системі є сертифікат «Slovo»
  (`Scripts/signing-identity.sh`) — ним, інакше тимчасовим підписом.
- Дані програми (модулі тощо) сценарій бере з сусіднього пакета `.app` у
  теці призначення, якщо він там є.
- NDI: покладіть `libndi.dylib` у теку призначення. yt-dlp в один файл:
  `Scripts/build-ytdlp.sh`.
- Самоперевірка:
  `Слово.app/Contents/MacOS/Slovo --selftest` — звіт у
  `~/Library/Logs/slovo-selftest.txt`; окремі розділи —
  `--check=планшет,медіа`.

### Android

Пульт і планшет збираються без Gradle: потрібні Android SDK
(build-tools і платформа) та JDK 17 або новіша.

```sh
Пульт/build.sh
Планшет/build.sh
```

Ключ підпису створюється під час першої збірки в `Службові/ключ.jks`.
Бережіть його: з іншим ключем нова версія не встановиться поверх старої.

## Будова

| Тека | Що там |
| --- | --- |
| `Sources/SlovoCore` | формати без інтерфейсу: модулі, пісенники, плани, налаштування, пошук |
| `Sources/Slovo` | програма на AppKit: вікно, виводи, пульт, самоперевірка |
| `Resources` | словники підписів (українська, англійська, німецька), умовчання |
| `Пульт`, `Планшет` | програми для Android; планшет бере спільний код із пульта |
| `Scripts` | збирання, підпис, yt-dlp |
| `Документація` | інструкції для користувачів |
