# Проповідник Слова — керування показом і план проповіді на комп'ютері з Windows

Файл: **«Проповідник Слова.exe»** (у релізі — `Propovidnyk-Slova-1.1.0.exe`).
Windows 10 і 11, 64-розрядні. Нічого встановлювати не треба: один файл, запустили — працює.

Це те саме, що планшет оператора й проповідника, тільки на звичайному
комп'ютері: **керування показом** (зал, вкладки, План та Історія, кнопки) і
**план проповіді**, який складається вдома, без зв'язку з програмою, а на
служінні однією кнопкою стає головним планом «Слова».

## Перший запуск

1. Завантажте файл і запустіть його. Windows може показати «Windows захистила
   ваш ПК» (програма не підписана сертифікатом Microsoft) — натисніть
   **«Докладніше»** → **«Усе одно запустити»**.
2. Перший запуск триває кілька секунд довше: Windows розпаковує програму.
3. Дані програма тримає в `%APPDATA%\Slovo Propovidnyk` — бібліотека перекладів і
   пісенників, плани, копії файлів планів. Поруч із .exe нічого не пише, тож файл
   можна тримати хоч у «Завантаженнях».

## Робоче місце: керування показом

Вікно влаштовано, як планшет:

- **Згори — вкладки програми**: Біблія, Пісні, Презентація, Медіа, Зображення,
  Екран, Текст. Клацнули — перемкнулася й програма; перемкнули на комп'ютері зі
  «Словом» — вікно йде слідом. Вкладка, на якій стоїть програма, позначена «●».
- **Посередині — зал**: те, що зараз на стіні, і текст живого слайда з
  передпоказом. Ведіть мишею по залу — на стіні йде **указка**; подвійне
  клацання знімає наближення.
- **Під залом — кнопки**: «◀ Назад», «Далі ▶», «Показати», «Сховати»,
  «Чорний екран», «Порожній».
- **Праворуч — План та Історія**: клацання по пункту виводить його в зал;
  «＋ Додати вибране» кладе в План те, що вибрано в програмі; «↑ Вище»,
  «↓ Нижче», «✕ Прибрати». Коли в «Слові» йде план проповіді, там же стоїть
  «Повернути план служіння».
- **Ліворуч — вміст вкладки**:
  - **Біблія**: переклад, книга, розділ, вірші (клацання позначає, подвійне —
    одразу в зал), «У передпоказ», «Показати в залі», «＋ У План»; угорі —
    пошук за словами, знайдене клацанням іде в передпоказ, подвійним — у зал.
  - **Пісні**: пісенник, відбір за номером чи словами назви, клацання по пісні —
    у передпоказ, кнопки частин («Куплет 1», «Приспів») — у зал.
  - **Презентація**: колоди й сторінки, знизу — велика мініатюра вибраної
    сторінки; «Файл із цього комп'ютера…» відкриває в «Слові» PDF чи PowerPoint
    просто звідси.
  - **Медіа**: список плеєра, ▶/⏸, ⏹, перемотка, гучність, «Без звуку»,
    «На екран», «Повтор».
  - **Зображення**: картинки програми й «Фото з цього комп'ютера…» — одразу в зал.
  - **Екран**: монітори й вікна комп'ютера зі «Словом», «Зупинити показ».
  - **Текст**: заголовок і текст оголошення — «У передпоказ» чи «Показати в
    залі», сторінки ◀ ▶.

## Переклади й пісенники

Кнопка **«Переклади й пісенники»** вгорі:
- **«Зі «Слова»»** — переклади й пісенники, які є в програмі (потрібне підключення);
- **«З GitHub»** — переклади з каталогу модулів «Цитати з Біблії» (потрібен інтернет);
- **«З файла…»** — zip «Цитати з Біблії», модуль MyBible `.SQLite3`, пісенник
  VisioBible `.vbm` чи пісенник «Слова» `.songbook`.

Чого в «Слові» на служінні не виявиться (модулі з GitHub і з файла), «Проповідник»
відвезе туди сам, і програма поставить їх собі.

## Складання плану

- **Три кроки** вгорі: «① Додайте пункти» → «② Перевірте порядок» → «③ Завантажте в
  «Слово»»; поточний підсвічено.
- **Біблія**: переклад → книга → розділ, клацніть потрібні вірші (ще раз — зняти
  позначку) → «＋ Додати вірші в план» або «＋ Увесь розділ».
- **Пісні**: пісенник, відбір за номером або словами назви, праворуч — слова пісні;
  «＋ Додати пісню в план» (або подвійне клацання).
- **Файл**: презентація (PDF, PowerPoint), картинка чи відео — «Вибрати файл…» або
  просто перетягніть файл у вікно. Файл копіюється в програму.
- **Текст**: заголовок і текст оголошення → «＋ Додати текст у план».
- **Праворуч — сам план**: «У плані: N», пункти з номером і значком, «↑ Вище»,
  «↓ Нижче», «✕ Прибрати» (або клавіша Delete).
- **Мої плани (N)** біля назви: інший план, «＋ Новий план», «Видалити цей план».
  Усе зберігається само.

## На служінні

1. **«Підключення…»** вгорі → «Шукати в мережі» (комп'ютер зі «Словом» і цей
   комп'ютер — в одній мережі; у «Слові» пульт увімкнено: Параметри → Remote API,
   порт 8103) → виберіть «Слово» → «Перевірити й запам'ятати». Не знайшлося —
   адресу, порт і PIN можна ввести вручну.
   Пошук іде трьома шляхами одразу: розсилка по мережі, ім'я `slovo.local` і
   обхід своєї мережі стуком у порт 8103 — останній працює навіть тоді, коли
   брандмауер Windows не пропускає відповідь на розсилку.
2. Під великою синьою кнопкою видно, чи «Слово» на зв'язку.
3. **«⬆ Завантажити в «Слово»»**: файли плану їдуть у програму, переклади й
   пісенники, яких там немає, програма ставить собі, — і план стає головним.
4. Відкривається **керування показом**: зал картинкою, пункти плану (клацання —
   пункт у залі), «◀ Назад», «Далі ▶», «Показати», «Сховати», «Чорний екран».
5. Коли закінчили — **«Повернути план служіння»**: план служіння не губився, його
   лише відкладено на час проповіді.

Мова: «Мова / Language» вгорі — «Авто» (за мовою Windows: українська для
української й російської, інакше англійська), «Українська», «English».

## Якщо щось не так

- «Слово» не знаходиться в мережі: чи відкрите «Слово», чи ввімкнено пульт, чи
  не гостьова мережа з ізоляцією клієнтів. Введіть адресу вручну — її видно в
  «Слові»: Параметри → Remote API.
- ««Слово» не відповіло вчасно»: комп'ютер зі «Словом» зайнятий чи мережа
  повільна — спробуйте ще раз; великий переклад по Wi-Fi може йти хвилину-дві.
- Щоденник програми: `%APPDATA%\Slovo Propovidnyk\journal.txt`.

## Для розробника

C# .NET 10 + Avalonia 11.3, збирається **на Mac** в один самодостатній `win-x64`
.exe (~47 МБ): `./build.sh` → `~/Documents/Слово/Проповідник Слова.exe`.
Інструмент — у `toolchain/` (у git не йде; клон APFS тієї самої теки з
`cloude_work/tools/nas-migrator-win`, місця не займає; як отримати заново —
друкує `build.sh`).

Код перенесено з планшета (Планшет/…/SermonActivity, SermonPlan, Library,
ModuleReaders і Пульт/…/Api, Discovery) — ті самі правила розбору модулів, той
самий формат плану й той самий канал: HTTP-пульт «Слова» на 8103, PIN заголовком
`X-Slovo-Pin`, пошук розсилкою «SLOVO?» на UDP 8104.

| Файл | Що в ньому |
| --- | --- |
| `Sources/Api.cs` | запити до «Слова»: стан довгим опитом, команди, бібліотека, файли, імпорт модуля, план проповіді |
| `Sources/Discovery.cs` | пошук «Слова» в мережі |
| `Sources/Library.cs` | своя бібліотека в SQLite (книги, вірші, пісні, частини) |
| `Sources/ModuleReaders.cs` | SLOVO-BIBLE, «Цитата з Біблії», MyBible, `.vbm`, `.songbook`, кодування, наскрізні номери книг |
| `Sources/SermonPlan.cs` | план і його пункти, збереження |
| `Sources/Services.cs` | звідки брати модулі; завантаження плану в «Слово» |
| `Sources/Views/MainWindow*.cs` | робоче місце: вкладки, зал, План та Історія, керування |
| `Sources/Views/PlanWindow.cs` | складання плану проповіді |
| `Sources/Views/LibraryWindow.cs`, `ConnectWindow.cs` | бібліотека й підключення |
| `Sources/Cli.cs` | `--selftest` без вікна |

**Перевірка без вікна** (і на Mac: `dotnet bin/Debug/net10.0/Propovidnyk.dll --selftest …`):

    Propovidnyk.exe --selftest [--module файл]… [--host адреса] [--port 8103] [--pin PIN] [--no-github] [--keep]

Бібліотека з файлів, зі «Слова» й з GitHub, план з усіх видів пунктів, пошук у
мережі, завантаження плану, пункт у залі, повернення плану служіння. Дані — у
тимчасовій теці; `--keep` лишає їх у справжній (щоб показати вікно з готовим
планом) і не завантажує план.

**Перевірка у Windows** — ВМ Parallels «Мой Boot Camp» через
`cloude_work/tools/nas-migrator-win/vm/exec.sh`: .exe копіюється в
`%LOCALAPPDATA%` під латинським ім'ям, вікно запускається фоновим викликом, кнопки
натискаються через UI Automation (Avalonia їх віддає з назвами), екран —
`prlctl capture`. Граблі: `$True` у PowerShell — зарезервоване ім'я; ВМ сама стає
на паузу, коли простоює; вікно-повідомлення в UIA — нащадок головного вікна, а не
окреме вікно верхнього рівня; «Слово» на Mac під навантаженням (Windows у ВМ
ставить оновлення) віддає переклад хвилинами — тайм-аути клієнта щедрі.
