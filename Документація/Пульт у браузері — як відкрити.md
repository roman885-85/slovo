# Пульт у браузері — «Слово» з будь-якого пристрою

Нічого ставити не треба: сторінку віддає сама програма «Слово». Підійде
будь-який сучасний браузер — на ноутбуці, iPad, Android-планшеті чи
телефоні. Інтернет не потрібен, досить тієї самої мережі Wi-Fi, у якій
комп'ютер зі «Словом» (будь-який комп'ютер, macOS 11 і новіші).

## Як відкрити
У браузері наберіть:

    slovo.local

Ім'я slovo.local оголошує в мережі сама програма — на тому комп'ютері, де
вона запущена, тож адреса всюди однакова. Без номера порту сторінка
відкривається, коли на тому комп'ютері вільний порт 80; якщо його зайняла
інша програма — наберіть з портом: slovo.local:8105. Якщо в мережі два «Слова», друге
зветься slovo-2.local (або дайте кожному своє ім'я в параметрах).

Підказка — у самій програмі: меню **Настройка → Пульт у браузері…** (або
**Помощь → Пульт у браузері…**) і кнопка «Як відкрити…» у Параметри →
Remote API. У вікні — адреса за ім'ям, **QR-код** для камери, адреса
цифрами (для старих Android, що не розуміють .local) і стан.

## Налаштування: Параметри → Remote API → «Пульт у браузері»
- **Відкривати пульт у браузері** — увімкнути чи вимкнути сторінку зовсім.
- **Порт** — нестандартний, 8105; якщо на цьому комп'ютері він зайнятий
  іншою програмою, під налаштуваннями буде написано — виберіть інший.
- **Пароль** — порожньо: без пароля; задали — сторінка спитає його
  (раз, далі пам'ятає). Пароль браузера окремий від PIN телефона.
- **Ім'я в мережі** — slovo (slovo.local); для другого залу — своє.
- **Відкривати й без номера порту (порт 80, якщо вільний)** — тоді досить
  набрати slovo.local. Під налаштуваннями видно, чи вийшло: «адреса без
  номера порту» або «порт 80 зайнятий — адреса з номером порту».
- **Лише перегляд** — сторінка показує зал, але не гортає й не виводить:
  для екрана музикантів чи проповідника.

Зміни діють після «Ок».

## Програми для Android
Обидві програми — «Пульт Слова» (телефон, Android 6+) і «Планшет Слова»
(Android 5+) — лежать усередині «Слова»:
- **за QR-кодом**: меню Настройка → «Програми для Android…» (або кнопка
  «Встановити за QR-кодом…») — наведіть камеру телефона чи планшета на
  код потрібної програми, файл завантажиться, торкніться його й дозвольте
  встановлення з браузера;
- **зі сторінки в браузері**: кнопка «Android» угорі — сторінка сама
  скаже, чи підходить програма цьому пристрою;
- **на комп'ютер**: «Зберегти…» там само.

Android попереджає про «невідомого розробника» — це очікувано для програм
не з Google Play: «Усе одно встановити».

## Що на сторінці
- згори — сім вкладок програми; вкладка сторінки й програми — одна;
- посередині — зал: указка мишею чи пальцем, наближення колесом чи щипком,
  подвійне клацання або «1:1» — зняти;
- праворуч — План та Історія, знизу — Назад, Далі, Показати, Сховати,
  Чорний екран, Порожній.
Клавіші: →/PageDown/пропуск — далі, ←/PageUp — назад, Enter — показати,
Esc — сховати, B — чорний екран.

## Не відкривається
- Пристрій і комп'ютер в одній мережі Wi-Fi? Гостьова мережа роутера часто
  не пускає до інших пристроїв.
- У вікні «Пульт у браузері» написано, що вимкнено чи порт зайнятий, —
  виправте в Параметри → Remote API.
- За ім'ям не відкривається — наберіть адресу цифрами з того самого вікна
  або наведіть камеру на QR-код.
